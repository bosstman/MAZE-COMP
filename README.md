# Maze Chomp

A Pac-Man-inspired browser maze game built with plain HTML, CSS and JavaScript. It uses original game code and simple canvas-drawn characters, with no external libraries or build tools.

## Play locally
1. Download or unzip this project.
2. Open `index.html` in a modern browser.

## Publish it on GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `maze-chomp`.
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.

## Controls
- Arrow keys or WASD: move
- Space: pause
- On mobile: use the directional buttons under the game board

## Features
- Score, lives and level counter
- Dots and power orbs
- Chasing ghosts that become vulnerable after collecting a power orb
- Multiple levels and mobile touch controls
